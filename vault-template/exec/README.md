# 🎯 exec/ · 正在做的事

> **手头同时只放 3〜7 件事。** 这里是你的"工作台"，只放当下要推进的。
> Your working memory — 3 to 7 active things, no more.

## 放什么
- 当前在做的任务
- 本周计划 / 待办清单
- 正在跟进的事（等回复、等结果）

## 规则
1. **超过 7 件**就太多了——挑最重要的留下，其余先放回 `inbox/` 或 `wiki/`。
2. 做完的任务：有价值的内容让 Friday 提炼进 `wiki/`，然后从这里移走。
3. 反复出现的同类任务，让 Friday 沉淀成 `skills/` 里的固定套路。

> 试试："Friday，把'本周要交季度报告'加到 exec。"
