# 📚 wiki/ · 长期知识库

> **值得长期留的，都在这。** 整理好的笔记、概念、人和事，用双链连成一张网。
> Your long‑term knowledge, linked into a web.

## 放什么
- 整理过的知识、方法、心得
- 重要的人、公司、项目（一个对象一篇）
- 概念解释、参考资料的摘要

## 规则
1. 每篇开头加 frontmatter（创建/更新日期、标签），Friday 会自动帮你加。
2. 用 `[[双链]]` 把相关的笔记连起来——在 Obsidian 里点一下就能跳转。
3. 文件名用中文、短、一看就懂。

> 这里一开始是空的，很正常。多和 Friday 聊，知识自然会沉淀进来。
