# ⚙️ skills/ · 固定套路 / 技能

> **重复的事，变成一键套路。** 你反复让 Friday 做的同一类事，沉淀成步骤，下次直接调用。
> Turn things you ask for again and again into reusable routines.

## 放什么
- 你常做的固定流程，比如"把今天的会议记录整理成纪要并提取待办"
- 让 Friday 按固定格式输出的模板

## 规则
1. 不用一开始就建。等某件事你做了三五次，再让 Friday "把这个流程存成一个技能"。
2. 一个技能 = 一篇 `.md`，写清楚：什么时候用、分几步、输出什么样。

> 进阶功能。新手可以先完全忽略这个文件夹，等用熟了再说。
