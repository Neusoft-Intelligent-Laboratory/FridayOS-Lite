# 📥 inbox/ · 随手记 / 收件箱

> **先接住，晚点再整理。** 这里是大脑的"入口缓冲区"，不是仓库。
> Capture fast, sort later. This is a buffer, not an archive.

## 放什么
- 突然冒出来的想法、灵感
- 聊天/会议里的一句关键话
- 待读的文章、链接
- 任何"不知道该放哪"的临时内容

## 规则
1. **只管记，别纠结分类**——分类是 Friday 的事。
2. 过几天没用的，就删掉。这里不囤积。
3. Friday 会定期帮你把这里的东西分流到 `exec/`（在做）或 `wiki/`（长期）。

> 试试对 Friday 说："帮我记到 inbox：……" —— 它会在这里建一条笔记。
