# Skill · 借调人选分析

**触发语**："帮 XX 项目找增援 / 借调人选"

## 步骤
1. 读目标项目页：缺什么角色、技术栈、缺到什么时候
2. 扫 wiki/项目/ 里状态为「收尾 ✅ / 维保中 / 半搁置 ⏸️」的项目 → 这些项目的成员是候选池
3. 对每个候选人查档案：技术匹配度、2025 绩效（要求 B+ 及以上）、老板备注里有无风险
4. 排除：正在关键项目（状态 ⚠️/🔥）的人、有离职风险标记的人

## 输出格式
| 人选 | 现在哪 | 为什么合适 | 风险 |
按推荐度排序，给出首选 + 备选，并注明信息依据（链接到档案）。
