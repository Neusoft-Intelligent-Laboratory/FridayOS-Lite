# Skill · 来访接待包

**触发语**："X 月 X 日 XX 来访，出全套接待包"
**场景**：资方 / 客户来访，原始日程通常是一封格式随意的邮件。

## 一次性输出五件套
1. **内部版日程表**：标准模板（时间/事项/地点/我方对接人/物料），逐项落实到人
2. **欢迎屏文案**：一句话，含来访方全称、日期
3. **司机简表**：只留司机需要的——航班号、落地时间、接送地点、联系人电话
4. **会议室座位图**：规则——主宾居中，左为上，投屏正对主宾；输出文字版桌签顺序
5. **准备清单**：访客证几张、投屏接口、餐饮禁忌、桌牌名单，逐条 checkbox

## 注意
- 来访人职级从 wiki/客户页或尽调资料里查，对不上的先问
- 禁忌信息（如忌辣）必须出现在准备清单第一条
