# Skill · 人才盘点

**触发语**："盘一下 XX 部门 / 全公司人才"

## 步骤
1. 数据源：raw/员工花名册2026-06.csv（全量） + wiki/团队/ 档案（细节）
2. 维度：绩效分布（连续 S/A 的明星员工）、薪酬公平性（同职级同岗位对比，标出倒挂）、
   司龄结构、关键岗位单点风险（某能力只有一个人会）
3. 交叉 exec/核心人才保卫战.md 的盯防名单

## 输出格式
> **明星名单**（连续高绩效，附建议动作）
> **倒挂清单**（同级薪酬差 >10% 的对子，附调薪建议）
> **单点风险**（唯一精通者名单）
口吻直接，给到可执行的建议，决定权留给老板。
