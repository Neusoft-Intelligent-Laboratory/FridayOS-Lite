# Skill · 简历入库与检索

**触发语**："把这批简历入库" / "找 XX 背景的候选人"

## 入库步骤
1. 剔除非简历文件（体检报告、学习资料混在邮件附件里很常见）
2. 按统一格式重命名：`岗位-姓名-年限-来源.pdf`（如 `后端P6-王某-5年-猎头.pdf`）
3. **文件名即索引**：以后检索按文件名扫，不用每次打开全文，省时省 token

## 检索玩法
- 竞对有变动 → 立刻筛出简历库中该公司人员，按时间段过滤近期的，定向联系
- 招聘需求 → 先扫库里存量再开新渠道
