# Skill · 经营周报

**触发语**："老规矩，出本周经营周报"

## 步骤
1. 读 `exec/本周计划.md`：三件大事的完成状态
2. 扫 `exec/` 其它进行中事项的最新进展
3. 扫 `inbox/` 本周新增条目，挑出需要老板拍板的
4. 检查 wiki/项目/ 中状态含 ⚠️ 或 🔥 的项目，摘录风险

## 输出格式（固定）
> **一、本周三件大事**（每件一行：状态 + 一句话进展）
> **二、风险雷达**（最多 3 条，按严重度排序）
> **三、待你拍板**（inbox 里悬而未决的事，给选项）
> **四、下周建议聚焦**（1-2 件）

口吻：结论先行，每条不超过两行，不堆形容词。
