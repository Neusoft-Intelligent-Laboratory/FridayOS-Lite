# Skill · 两表对账（白名单核对）

**触发语**："拿 A 表对 B 表，把异常标出来"
**典型场景**：IT 资产白名单 vs 在线记录、EHR 考勤 vs 项目工时、应发 vs 实发。
**效率**：1000+ 条人工对 1-2 天 → AI 不到几分钟。

## 步骤
1. 确认两表的关联键（工号 / IP / 姓名），有歧义先问老板
2. 双向核对：A 有 B 无、B 有 A 无、两边都有但字段冲突，三类都要查
3. 输出异常清单，**新增一列**写异常原因——**绝不覆盖原始数据**
4. 给一段两三行的结论：共几条异常、哪类最多、建议谁去跟进

## ⚠️ 踩坑经验（真实教训）
- 提示词一字之差结果完全不同："新增一列" ≠ "覆盖最后一列"；"最后一列" ≠ "最后一行最后一列"
- 原始表是 raw/ 的只读件，结果另存新文件，不动原件
