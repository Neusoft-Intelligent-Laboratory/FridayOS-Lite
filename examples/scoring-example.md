# 完整评级示例

> 用**虚构假数据**演示一次完整评级长什么样。岗位标准和候选人均为示例，仅用于展示结构。

[← 返回主页](../README.md)

---

## 示例岗位标准（虚构）

```yaml
岗位名称: 高级后端工程师（示例）
硬性要求:
  经验年限: 5 年以上后端开发
  必备技能: 精通一门主流后端语言 + 分布式系统经验
  地点: 可接受远程或一线城市
优先条件:
  - 有高并发系统经验
  - 稳定性好（单段经历 ≥ 2 年）
红线信号:
  - 近 3 年内 3 段以上短期（< 1 年）经历
```

---

## 示例候选人（虚构）

```
张三 · 8 年后端经验
- 公司 A（2018–2022）：分布式订单系统，日均千万级请求
- 公司 B（2022–至今）：核心支付链路
- 技能：精通 Java / Go，熟悉微服务架构
```

---

## AI 评级输出（示例）

```
候选人：张三
评级：⭐⭐⭐⭐⭐ / 五星
匹配度：高

理由：
  ✅ 命中硬性门槛：
     - 经验年限：8 年 > 5 年要求 ✓
     - 必备技能：精通 Java/Go + 分布式经验 ✓
  ⭐ 加分项：
     - 高并发经验：日均千万级请求，强相关 ✓
     - 稳定性：两段经历分别 4 年、2 年+，稳定 ✓
  ⚠️ 风险信号：无

建议动作：优先联系
一句话总结：硬性全中 + 高并发与稳定性双加分，是该岗位的理想画像。
```

---

## 对比：一个评级较低的候选人（示例）

```
候选人：李四
评级：⭐⭐ / 五星
匹配度：低

理由：
  ✅ 命中硬性门槛：
     - 经验年限：6 年 ✓
     - 必备技能：会 Python，但无分布式系统经验 ❌
  ⚠️ 风险信号：
     - 近 3 年有 3 段经历，均 < 1 年（命中一票否决）

建议动作：暂不考虑
一句话总结：缺核心的分布式经验，且稳定性命中红线，不建议推进。
```

---

> 这只是演示**结构**。你团队的真实标准、真实候选人画像，应该由你按 [评级教程](../docs/resume-scoring-skill.md) 自己定义。
